# Where's Mitch?

An original, animated hidden-object satire in which the player has ten clicks to find
Turtle Mitch before he escapes. The finished game will be a static HTML/CSS/JavaScript
package that works without an application server and can be deployed unchanged to
Cloudflare Pages or S3-compatible static hosting.

## Project Status

Planning is complete; implementation has not started.
