<task type="execute">
  <name>Implement the pure ten-click state machine</name>
  <read_first>
    `docs/GAME-DESIGN.md` Game State Machine and Click Rules; `src/core/reducer.ts`,
    `src/core/events.ts`, and `tests/unit/reducer.test.ts` if present.
  </read_first>
  <files>`src/core/reducer.ts`, `src/core/events.ts`, `tests/unit/reducer.test.ts`</files>
  <action>
    Implement pure initialization and exhaustive event reduction. Start creates round 1 with ten
    clicks and zero completed rounds. A valid playing-state miss decrements once; miss ten enters
    `mitch_escape` synchronously. A catch is accepted with ten through one clicks remaining and does
    not consume an attempt. Capture completion increments completed rounds once, advances the round,
    clears scene readiness, and resets clicks to ten. Escape completion enters game over. Inputs in
    title, paused, capture, transition, escape, and game-over modes are ignored. Restart creates a
    clean run while retaining settings/record snapshot. Do not mix timers, DOM, or sound into the
    reducer.
  </action>
  <acceptance_criteria>
    Tests cover initial ten, nine misses, tenth miss, tenth-attempt catch, ordinary catch, repeated
    outcome events, state locks, round reset, game-over stats, and restart. Attempts never become
    negative and an outcome can resolve only once.
  </acceptance_criteria>
  <verify>`npm run test:run -- reducer`; `npm run typecheck`.</verify>
</task>
